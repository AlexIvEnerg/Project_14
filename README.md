# Project_14

# Содержание проекта

 CollectionVars - класс Main содержит варианты применения коллекции List (в качестве обработки 		
 		размеров и весов коробок) и классов TreeSet и ArrayDeque. Также применяет кастомный класс Box и его наследника HeavyBox (в файле Box), и  класс SetOfNumbers, принимающий через консоль вводимые числа, передающй их в массив, также содержащий методы, устраняющие повторения чисел в массиве и выводящие на консоль содержимое коллекции Set.  
 		Класс Institution применяет коллекцию Set (производит отбор студентов по среднему баллу и их перевод на последующий курс) и использует кастомный класс Student. 
 		
 HashMapExample - класс Main применяет интерфейс HashMap для обработки информации о книгах, описываемых
		классом Book. Обращение к книге в словаре осуществляется по названию (ключу), а на консоль в перечеслениях выводятся данные о названии, авторе и стоимости книги. 		

 Iteratores - класс Main содержит варианты применения интерфейсов Iterator и Iterable в простом переборе 
		массивов с типами элементов Integer.

 Lambda_express(выражение) - под данным именем рассматриваются применения лямбда-выражений и функцион-х
		интерфейсов:
 		-and_link - класс Main содержит применение функцион-го интерфейса Supplier(вывод случайного числа)

 		-for_consumer - класс Main содержит применение двух функцион-х интерфейсов, Consumer с использованием кастомного класса HeavyBox(содержащего сообщения, выводимые на консоль), и Function, выводящего сообщение о типе поступающего числа  

 		-for_interface - класс Main содержит применение двух функцион-х интерфейсов, один из которых - Predicate, а другой - кастомный Printable, выводящий на консоль некоторую строку

 Listes - класс Main содержит применение классов ArrayList и LinkedList для оценки продолжительности 
 		выполнения набора случайных чисел в данные списки
